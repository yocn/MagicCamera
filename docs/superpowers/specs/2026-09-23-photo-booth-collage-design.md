# 大头贴拼贴设计

## 目标

为贴纸相机增加大头贴模式：选择排版、花边和拍法后连续拍摄多张照片，自动合成一张多格拼贴图并保存到系统照片。贴纸与既有拍摄体验保持可用。

## 用户体验

- 屏幕右侧快捷键区在贴纸、边框之下新增大头贴入口，共三个图标。
- 点击后从底部弹出大头贴面板，三排横滑选择器加一个开始按钮：排版、花边、拍法。
- 选定后点击“开始拍摄”，面板关闭并进入大头贴模式。预览保持全屏取景，不切分成小格。
- 屏幕左上角显示拼贴进度缩略图：已拍格子填入照片，当前格粉色描边闪烁。
- 拍满全部格子后自动合成、保存并提示“拍好啦！已经保存到系统照片 ✨”，随后退出大头贴模式。
- 大头贴模式中可随时点击进度缩略图上的取消按钮放弃本次拍摄，已拍照片全部丢弃、不保存。

## 排版

画布宽度固定 1440 像素，高度由排版宽高比决定。格子矩形以画布归一化坐标定义，花边的外边距与格缝在此基础上内缩。

| 排版 | 画布宽高比 | 格数 | 格子归一化矩形 |
| --- | --- | --- | --- |
| 四宫格 | 1:1 | 4 | (0,0,.5,.5) (.5,0,.5,.5) (0,.5,.5,.5) (.5,.5,.5,.5) |
| 上二下一 | 1:1 | 3 | (0,0,.5,.5) (.5,0,.5,.5) (0,.5,1,.5) |
| 上一下二 | 1:1 | 3 | (0,0,1,.5) (0,.5,.5,.5) (.5,.5,.5,.5) |
| 竖排四格 | 1:3 | 4 | 四个 (0, n×.25, 1, .25) |
| 竖排三格 | 1:2.25 | 3 | 三个 (0, n×⅓, 1, ⅓) |
| 左大右二 | 1:1 | 3 | (0,0,.62,1) (.62,0,.38,.5) (.62,.5,.38,.5) |
| 上下二格 | 1:1.5 | 2 | (0,0,1,.5) (0,.5,1,.5) |
| 六宫格 | 1:1.5 | 6 | 2 列 3 行等分 |
| 九宫格 | 1:1 | 9 | 3 列 3 行等分 |

默认排版为四宫格。

## 花边

花边是参数化绘制，不使用 PNG 素材，因此任何排版都能自适应。外边距与格缝按画布宽度取比例，圆角按格子短边取比例。

| 花边 | 外边距 | 格缝 | 圆角 | 底色 | 装饰 |
| --- | --- | --- | --- | --- | --- |
| 无边 | 0 | 0 | 0 | 透明 | 无 |
| 经典白边 | 0.035 | 0.025 | 0 | 白 | 无 |
| 奶油圆角 | 0.04 | 0.03 | 0.08 | #FFF6E9 | 无 |
| 波浪花边 | 0.05 | 0.03 | 0.06 | 白 | 画布外圈波浪描边 |
| 彩虹条 | 0.045 | 0.028 | 0.05 | 白 | 画布外圈彩虹渐变描边 |
| 星星点点 | 0.045 | 0.03 | 0.07 | #FFE9F2 | 四角星星图形 |

默认花边为经典白边。

## 拍法

| 拍法 | 行为 |
| --- | --- |
| 连拍 3 秒 | 点一次快门后每格 3 秒倒计时自动拍摄，直到拍满 |
| 连拍 5 秒 | 同上，倒计时改为 5 秒 |
| 逐格手动 | 每格单独点击快门，两格之间可以更换贴纸和镜头 |

- 倒计时复用现有的 `TimerCountdownDigitView` 数字动画与快门黑闪、音效。
- 连拍模式下两格之间留 0.8 秒缓冲，让上一格的快门效果播完再开始下一轮倒计时。
- 大头贴模式下忽略设置中的 3 秒定时开关，倒计时完全由拍法决定。
- 默认拍法为连拍 3 秒。

## 技术架构

- `Core/CollageLayout.swift`：排版枚举，提供画布宽高比、格子归一化矩形和标题。不依赖 UIKit。
- `Core/CollageStyle.swift`：花边枚举，提供外边距、格缝、圆角、底色和装饰类型。不依赖 UIKit。
- `Core/CollageSession.swift`：拍摄状态机，持有排版、拍法与已拍张数，提供当前格索引、剩余张数和完成判定。不持有图片，保持可单测。
- `Services/CollageComposer.swift`：输入已合成的单格图片数组、排版与花边，输出最终拼贴图。
- `Views/CollageTrayView.swift`：三排选择器面板，与贴纸面板同样的 `ultraThinMaterial` 风格和关闭按钮。
- `Views/CollageProgressView.swift`：左上角进度缩略图与取消按钮。
- `CameraScreen` 新增大头贴模式状态：当前 session、已拍图片数组、倒计时任务。

单格图片继续由现有 `PhotoComposer` 合成，贴纸、边框、画中画照旧生效；`CollageComposer` 只负责把成品按格子中心裁剪后排版并绘制花边。

## 数据与坐标

- 每格源图按该格宽高比中心裁剪后填入，不拉伸。
- 每格合成使用该格拍摄瞬间的贴纸图层快照，逐格手动模式下各格可以不同。
- 进度缩略图宽度取 96 点与预览区短边 22% 中的较小值，按排版宽高比显示，位置在左上角，左边距 24 点，顶边距沿用 `CameraScreenChrome.topPadding`。
- 大头贴模式下锁定画幅切换，拍摄期间“全屏 / 3:4”按钮不可用，退出后恢复。
- 大头贴模式下保留镜头切换与贴纸编辑。

## 错误处理与降级

- 拍摄途中相机中断、权限丢失或应用进入后台时取消本次大头贴，丢弃已拍照片并提示中断原因，回到普通拍摄模式。
- 单格拍摄失败时终止整次拍摄并提示，不保存残缺拼贴。
- 合成或保存失败时沿用现有提示路径，已拍照片不重试。
- 画中画双摄与大头贴可同时使用，小窗按每格独立合成。

## 不做的部分

- 拍完后的预览编辑页、单格重拍。
- 拼贴模板收藏、最近使用记录。
- 从系统相册选图拼贴。
- 拼贴视频或动图。

## 测试与验收

- 单元测试 `CollageLayout`：每种排版的格数、格子不重叠、并集覆盖整块画布、画布宽高比正确。
- 单元测试 `CollageStyle`：各花边参数在合法区间，无边样式的外边距与格缝为零。
- 单元测试 `CollageSession`：逐格推进、完成判定、取消后计数归零、格数与排版一致。
- 单元测试 `CollageComposer`：传入多张纯色图，验证输出尺寸符合排版宽高比，且每格中心像素取到对应源图颜色。
- 模拟器：验证面板三排选择、进度缩略图、取消流程、贴纸与边框回归正常。
- 真机：四宫格连拍 3 秒、竖排四格连拍 5 秒、上二下一逐格手动各完整拍摄一次，检查系统照片中的成片格子顺序、裁剪、花边与贴纸层级；确认拍摄途中切后台不会残留状态。
