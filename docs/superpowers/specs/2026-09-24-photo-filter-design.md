# 照片滤镜设计

## 目标

给相机加一组简单滤镜（暖色、冷色、黑白、漫画感），作用于整个画面：照片、贴纸、涂鸦、边框统一调色，预览与成片效果一致。

## 滤镜作用位置

滤镜是**最后一层**，套在所有图层之上：

```
预览：ZStack{ 相机预览 → 贴纸 → 涂鸦 → 边框 } → 滤镜
成片：PhotoComposer 合成完所有图层 → 滤镜 → 存相册
```

因此贴纸、涂鸦、边框都会跟着变调——黑白滤镜下整张作品都是灰的，这是预期效果而非缺陷。

这个位置的选择同时避开了改相机会话：不需要 `VideoDataOutput`，不需要 Metal 渲染管线，预览层、贴纸坐标、画中画几何全部不受影响。

## 滤镜清单与参数

每个滤镜由三个参数描述：通道乘数、饱和度、对比度。

| 滤镜 | 通道乘数 (R, G, B) | 饱和度 | 对比度 |
| --- | --- | --- | --- |
| 原图 | 1.00, 1.00, 1.00 | 1.00 | 1.00 |
| 暖阳 | 1.00, 0.94, 0.84 | 1.05 | 1.02 |
| 清凉 | 0.88, 0.95, 1.00 | 1.00 | 1.02 |
| 黑白 | 1.00, 1.00, 1.00 | 0.00 | 1.08 |
| 漫画 | 1.00, 0.98, 0.96 | 1.55 | 1.35 |

默认原图。

## 预览与成片如何保持一致

两侧用**同一组参数**和**等价的数学操作**：

- 预览：`.colorMultiply(通道乘数)` + `.saturation(饱和度)` + `.contrast(对比度)`
- 成片：`CIColorMatrix`（逐通道乘法）+ `CIColorControls`（饱和度、对比度）

关键在于用 `CIColorMatrix` 而不是 `CITemperatureAndTint` 做色调：前者就是逐通道乘法，与 `colorMultiply` 的数学完全等价；后者走的是色温模型，与 SwiftUI 侧对不上。`CIColorControls` 的 saturation / contrast 语义也与 SwiftUI 对应的 modifier 一致。

两条路径仍是不同的实现，细微色差无法完全排除，但因为算子同构，差异是全局且可控的。

## 用户体验

- 屏幕右侧快捷键区新增滤镜入口，共五个：贴纸、边框、大头贴、涂鸦、滤镜。
- 点滤镜图标从底部浮出横滑滤镜条，每项显示滤镜名；当前选中项高亮。
- 选中即生效，预览实时变化。
- 滤镜条不遮挡快门，可以边看效果边拍。
- 再点滤镜图标或滤镜条上的完成按钮收起，选中的滤镜继续生效。
- 选了非原图滤镜时，右侧滤镜图标转为高亮色，提示当前有滤镜在生效。

## 技术架构

- `Core/PhotoFilter.swift`：滤镜枚举与参数表，纯逻辑，不依赖 UIKit，可单测。
- `Views/PhotoFilterModifier.swift`：把参数映射成 SwiftUI modifier，供预览使用。
- `Services/PhotoFilterRenderer.swift`：把参数映射成 CIFilter 链，把 `UIImage` 过一遍滤镜，供成片使用。
- `Views/PhotoFilterBar.swift`：底部横滑滤镜条。
- `PhotoComposer`：合成流程末尾应用滤镜。
- `CameraScreen`：持有当前滤镜与滤镜条开关。

## 行为约定

- 滤镜选择跨拍摄保留，不会拍一张重置一次。
- 滤镜不持久化到下次启动：每次打开应用回到原图，避免上次随手选的滤镜影响这次拍摄而用户没察觉。
- 大头贴模式下每一格都套用当前滤镜，与贴纸、涂鸦的处理方式一致。
- 滤镜与涂鸦模式可同时开启，互不冲突。

## 不做的部分

- 滤镜强度调节滑块。
- 自定义滤镜、保存滤镜预设。
- 只给照片上滤镜而保留贴纸原色的分层模式。
- 半调网点之类的重度风格化（`CIComicEffect` 效果过强，不适合儿童照片）。

## 测试与验收

- 单元测试 `PhotoFilter`：原图滤镜是恒等参数（乘数全 1、饱和度 1、对比度 1）；黑白滤镜饱和度为 0；所有滤镜的乘数落在 0 到 1、饱和度与对比度为正数。
- 单元测试 `PhotoFilterRenderer`：给一张纯色图套黑白滤镜后，输出像素的 R、G、B 三通道相等；套原图滤镜后像素与输入一致。
- 单元测试 `PhotoComposer`：传入滤镜后，成片中贴纸区域的颜色同样被滤镜影响，确认滤镜作用在合成之后而非之前。
- 模拟器：滤镜条五项都能切换，选中态正确；选非原图时右侧图标高亮。
- 真机：逐个滤镜看实时预览效果；拍照后对比成片与预览的色调是否接近；大头贴模式下每格都带滤镜。
