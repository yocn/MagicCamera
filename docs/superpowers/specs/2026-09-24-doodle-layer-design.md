# 涂鸦图层设计

## 目标

在相机预览上叠一层透明画布，手指可以直接涂鸦，拍照时把涂鸦合成进成片。涂鸦与贴纸互不干扰。

## 用户体验

- 屏幕右侧快捷键区新增画笔入口，共四个：贴纸、边框、大头贴、涂鸦。
- 点画笔进入涂鸦模式：贴纸层锁定不响应手势，底部快门上方浮出两行工具条，画笔图标转为高亮色。
- 再点画笔图标或工具条上的“完成”退出涂鸦模式，贴纸恢复可编辑。
- 涂鸦模式下快门照常可用，可以边画边拍。
- 工具条第一行是 8 个颜色，第二行是 3 档粗细、橡皮、撤销、清空、完成。
- 所有工具按钮不小于 44 点，适合小孩点按。

## 图层顺序

自下而上：相机预览 → 画中画小窗 → 贴纸 → **涂鸦** → 边框 → 大头贴浮层 → 界面控件。

涂鸦在贴纸之上，所以可以画在贴纸上；在边框之下，因为边框是最外层画框，不该被涂掉。

大头贴浮层排在涂鸦之上，它是操作控件而非画面内容：涂鸦模式下浮层仍可拖动和关闭，代价是浮层遮住的那一小块画不上笔画，把浮层拖开即可。

## 调色板与笔形

| 颜色 | RGB |
| --- | --- |
| 草莓红 | 0.95, 0.30, 0.36 |
| 蜜橘橙 | 1.00, 0.60, 0.25 |
| 柠檬黄 | 1.00, 0.85, 0.30 |
| 青草绿 | 0.45, 0.80, 0.45 |
| 天空蓝 | 0.35, 0.68, 0.95 |
| 葡萄紫 | 0.66, 0.50, 0.90 |
| 泡泡粉 | 1.00, 0.62, 0.78 |
| 奶油白 | 1.00, 1.00, 1.00 |

粗细三档：细 6 点、中 14 点、粗 26 点。默认泡泡粉 + 中档。

笔形固定用 `PKInkingTool.InkType.pen`，不暴露铅笔、马克笔等选项，避免小孩被太多选择卡住。

## 技术架构

- `Core/DoodleTool.swift`：调色板、粗细档位、当前工具状态。纯逻辑，不依赖 UIKit，可单测。
- `Views/DoodleCanvasView.swift`：`PKCanvasView` 的 `UIViewRepresentable` 封装，把工具状态映射成 `PKInkingTool` / `PKEraserTool`。
- `Views/DoodleToolbar.swift`：两行工具条。
- `Services/PhotoComposer.swift`：新增可选的涂鸦图输入，画在贴纸之后、边框之前。
- `CameraScreen` 持有涂鸦模式开关、工具状态和当前 `PKDrawing`。

关键实现约束：

- `drawingPolicy` 必须设为 `.anyInput`。默认策略在支持 Apple Pencil 的场景下会拒绝手指输入，iPhone 上必须显式放开。
- 系统工具箱不显示，工具完全由自己的按钮驱动。
- 退出涂鸦模式时把画布的 `isUserInteractionEnabled` 置为 false，手势自然穿透回贴纸层。
- 撤销直接操作 `PKDrawing.strokes` 回退最后一笔，不走 `PKCanvasView` 的 `undoManager`：后者由 UIKit 响应链管理，在 SwiftUI 里取用不稳。
- 清空前把整幅暂存一份，撤销时优先恢复这一份，所以误触清空能一键撤回；清空后只要又画了新笔，这份暂存立即作废。

## 数据与坐标

- 画布尺寸与预览内容矩形一致，涂鸦坐标即预览坐标。
- 合成时用 `drawing.image(from: previewBounds, scale: 照片宽 / 预览宽)` 导出，再绘制到成片画布上，保证与预览所见一致。
- 大头贴模式下每一格都带上拍摄瞬间的涂鸦，与贴纸处理方式一致。

## 行为约定

- 拍完照涂鸦保留，不自动清空，与贴纸现有行为一致。
- 切后台再回来涂鸦保留。
- 涂鸦模式下画幅切换按钮禁用：改画幅会改变预览矩形尺寸，已画的笔画无法正确映射。
- 相机中断或权限异常不影响涂鸦，画布独立于相机会话。

## 不做的部分

- 铅笔、马克笔、蜡笔等多种笔形。
- 压感与倾斜（iPhone 无 Apple Pencil）。
- 涂鸦的保存与再编辑：涂鸦只存在于当前拍摄会话，不写入文件。
- 形状识别、贴图笔刷、渐变笔。

## 测试与验收

- 单元测试 `DoodleTool`：调色板颜色不重复且数量为 8、三档粗细严格递增、切换到橡皮再切回画笔时颜色与粗细保持不变。
- 单元测试 `PhotoComposer`：传入一张纯色涂鸦图，验证成片对应位置取到该颜色，且边框仍绘制在涂鸦之上。
- 模拟器：验证进入涂鸦模式后贴纸不再响应拖动，退出后恢复；工具条按钮切换正确。
- 真机：手指画线流畅、颜色与粗细符合预期、橡皮能擦、撤销与清空可用；拍照后成片中的涂鸦位置与预览一致；大头贴模式下每格都带涂鸦。
