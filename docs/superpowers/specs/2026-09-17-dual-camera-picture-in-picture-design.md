# 双摄画中画设计

## 目标

在支持多摄像头的 iPhone 上，为贴纸相机提供前后摄像头同时预览的画中画模式：后摄为主画面，前摄为可拖动的小窗，拍照后将两路画面、贴纸和边框合成为一张照片。

## 用户体验

- 设置菜单新增“画中画双摄”开关，仅当设备支持前后摄同时采集时显示。
- 开启后，后摄保留为主预览；前摄以带白色描边的圆角小窗显示在主预览右上方。
- 小窗可拖动，并限制在主画幅内；默认位置为右上。
- 拍照成片以主画幅为画布：后摄作为底图，前摄小窗按当前的位置与圆角遮罩叠加；既有贴纸和边框继续叠加在最上方。
- 关闭双摄后恢复当前单摄模式，前后镜头切换功能保持现状。

## 设备能力与降级

- 运行时先检查 `AVCaptureMultiCamSession.isMultiCamSupported`，再确认当前设备发现会话列出的 supported multi-camera device set 包含目标前后摄组合。
- 不支持、配置失败、会话中断或系统压力过高时：自动关闭双摄，恢复当前单摄预览，并显示“这台设备暂不支持双摄画中画。”提示。
- 模拟器始终按不支持处理；入口不显示，现有贴纸编辑功能继续可用。

## 技术架构

- `CameraService` 保持公开的主 `AVCaptureSession` 给主预览使用；新增双摄模式时以 `AVCaptureMultiCamSession` 配置前后输入、两路 `AVCaptureVideoDataOutput` 和主路 `AVCapturePhotoOutput`。
- 为保证图片成片速度和稳定性，首版不录制双摄视频。主路仍用 `AVCapturePhotoOutput` 拍摄高质量静态照片；前摄通过视频数据输出缓存最近一帧。
- 主预览继续使用 `AVCaptureVideoPreviewLayer`。前摄小窗新增独立的 preview layer/view，绑定同一个多摄会话中的前摄连接。
- `PictureInPictureLayout` 负责根据主画幅和小窗归一化中心位置计算预览与最终合成矩形；它不依赖 UIKit 视图，方便单元测试。
- `PhotoComposer` 新增可选的 picture-in-picture 输入：先裁主图到当前画幅，再将已归一化、镜像纠正的前摄帧按 `PictureInPictureLayout` 叠加，最后绘制贴纸与边框。

## 性能与画质

- 双摄会话使用 `inputPriority`；前摄小窗输出使用较低分辨率视频帧，主路静态图片保持 `AVCapturePhotoOutput`。
- 多摄配置完成后检查 `hardwareCost` 与 `systemPressureCost`。若预算不可用或达到临界状态，退出双摄，不持续重试。
- 应用进入后台、离开相机页或切换回单摄时停止前摄连接与输出，释放带宽和功耗。

## 数据与坐标

- 小窗位置以主画幅的归一化中心保存，横纵坐标均限制在可见主画幅内。
- 小窗尺寸固定为主画幅短边的 30%，圆角为小窗边长的 14%，白色边线为小窗边长的 1.5%。
- 自拍小窗预览与成片均镜像；后摄主路不镜像。
- 贴纸坐标继续以主画幅归一化坐标计算，不允许贴到前摄小窗内部。

## 测试与验收

- 单元测试 `PictureInPictureLayout`：默认右上位置、拖动边界裁剪、预览尺寸与成片尺寸映射一致。
- 单元测试 `PhotoComposer`：给定两张纯色图片，验证前摄小窗覆盖正确位置且边框、贴纸仍位于其上方。
- `CameraService` 测试可将能力检查抽成无 AVFoundation 副作用的策略类型，验证不支持时不暴露双摄开关。
- 模拟器：验证单摄界面、贴纸、边框、画幅、设置菜单回归正常。
- 支持的真机：开启双摄后验证两路预览、小窗拖动、拍照成片、关闭后回归单摄；连续拍 10 张确认没有崩溃或明显卡顿。
