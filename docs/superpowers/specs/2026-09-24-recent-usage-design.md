# 贴纸与边框最近使用设计

## 目标

贴纸面板和边框面板各自记住最近用过的条目，放在分类条最左边的「最近」页，省去每次从上百个素材里翻找。

## 用户体验

- 两个面板的分类条最左侧新增「最近」胶囊，图标用时钟。
- 「最近」页用 4 列网格，最多显示 16 个（4 排）。
- 选中任意贴纸或边框即写入对应的最近列表。
- 排序规则：刚用的插到第一位；再次用到列表里已有的条目，把它提到第一位；超过 16 个时挤掉最后一个。
- 打开面板时默认停在「最近」页；列表为空时回退到原来的默认分类（贴纸是发型，边框是当前边框所在分类）。
- 列表为空时「最近」页显示一句占位文字，不显示空网格。

## 数据模型

`RecentUsageList` 放在 `Core/`，不依赖 UIKit，可单测：

- `items: [String]`，贴纸存 assetName，边框存 `FrameStyle.rawValue`。
- `capacity` 固定 16。
- `use(_ id:)`：先移除同 id 的旧条目，插到第 0 位，超出容量时从尾部砍掉多余的。

贴纸与边框各一份，互不影响。

## 持久化

用 `UserDefaults` 存字符串数组，两个 key 分别是 `recentStickers` 和 `recentFrames`，落盘方式与现有 `CameraSoundPreference` 一致。应用重启后最近列表仍在。

## 失效条目过滤

存进去的是字符串 id，素材被删除或改名后会失效。渲染前统一过滤：贴纸查不到图片的丢弃，边框在 `FrameStyle(rawValue:)` 解析失败的丢弃。项目里的边框素材仍在频繁增删，没有这层过滤会出现空白格。

过滤只影响显示，不回写存储，避免一次素材临时缺失就永久抹掉用户的使用记录。

## 不做的部分

- 手动删除单条最近记录。
- 收藏（与最近使用是两套东西，不在本次范围）。
- 跨设备同步。
- 最近使用的次数统计或排序权重。

## 测试与验收

- 单元测试 `RecentUsageList`：新条目插到首位、重复使用提到首位且不产生重复、超出 16 条时砍掉最尾、容量边界（刚好 16 条不丢）。
- 单元测试持久化：写入后用新实例读出来顺序一致。
- 模拟器：两个面板的分类条最左都有「最近」；空列表时显示占位文字且默认停在原分类；用过几个之后重新打开面板，默认停在「最近」且顺序正确。
- 真机：贴纸和边框各用若干个，杀掉应用重开，确认最近列表还在、顺序没乱。
