# 萌趣贴纸相机设计

## 目标

为孩子制作一款离线、易操作的 iPhone 拍照应用：实时预览、拍照、保存成片到系统照片，并在成片中保留多个可自由摆放的萌系贴纸。

## 产品体验

- 使用前置相机作为默认镜头，可切换后置镜头；主界面仅保留系统照片、快门、切换镜头和贴纸四个主要入口。
- 贴纸入口打开底部抽屉，提供约 30 个内置 PNG，分类为动物、彩虹星星、爱心甜点和装扮。
- 每次选择都会将一个贴纸加入预览画布。贴纸可点选、拖动、双指缩放/旋转、删除，且支持撤销最近一次操作。
- 快门拍摄原始照片后，以预览中贴纸的变换结果合成一张新图并保存至系统照片库。
- 相册按钮在自用安装场景下尝试使用非公开系统照片跳转；失败时仍保留已保存照片并提示用户自行打开“照片”。

## 技术约束

- 使用 SwiftUI、AVFoundation、Photos 与 Core Graphics，不引入第三方依赖；最低支持 iOS 16。
- 相机预览采用 `AVCaptureVideoPreviewLayer` 的 SwiftUI 封装。拍摄采用 `AVCapturePhotoOutput`。
- 以预览内容矩形为坐标基准保存贴纸变换；合成时映射到原图像素坐标，并处理设备方向与前置镜像。
- 保存仅请求“添加照片”权限；相机不可用、权限被拒或保存失败时必须留在应用内显示明确中文提示。
- 首版不包含登录、网络、广告、视频、外部贴纸导入、应用内涂鸦或内置照片库管理。

## 验收

- 真机上可预览、切换镜头、拍摄并在系统照片中看到成片。
- 同一画面可添加至少两个贴纸；拖动、缩放和旋转后的成片位置与预览视觉一致。
- 照片权限或相机权限拒绝时，应用不崩溃且提供“前往设置”的引导。
